# Julia project template

Use this template to start a Julia project for data analysis. One script
installs Julia, the VS Code extension, and a set of packages.

Select the instructions for your operating system:

- Linux and macOS (`setup.sh`): [README-linux-macos.md](README-linux-macos.md)
- Windows (`setup.ps1`): [README-windows.md](README-windows.md)
